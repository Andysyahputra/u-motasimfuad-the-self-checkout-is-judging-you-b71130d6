An entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6) "The Self-Checkout Is Judging You" bounty. `main.ts` (Node 22, standard library only) writes one funny line in the voice of a smug self-checkout machine to `/output/entry.txt`:

> You scanned three bags of chips — clearly you think 'share size' means 'my size'.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
